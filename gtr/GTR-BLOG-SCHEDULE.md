## Content Production Workflow

### Week Before Publish
- [ ] Research current Melbourne market data (median price, DOM, inventory)
- [ ] Write draft (target word count + 10%)
- [ ] Add 2–3 internal links to GTR pages
- [ ] Add 1 external link to authoritative source (NAR, Brevard County records, etc.)
- [ ] Optimize title < 60 chars, meta description < 155 chars
- [ ] Include 1 original/local image with geo-tagged EXIF (if possible)
- [ ] Add FAQ section with 4–6 questions for FAQPage schema

### Publish Day
- [ ] Post to WordPress with Yoast SEO green lights
- [ ] Add `Article` schema via Yoast or custom JSON-LD
- [ ] Set featured image (compressed WebP, < 100 KB)
- [ ] Share to GMB as an update
- [ ] Share to Facebook Business Page
- [ ] Request indexing in GSC (URL Inspection tool)

### Week After Publish
- [ ] Monitor GSC for impressions and clicks
- [ ] Respond to any comments within 24 hours
- [ ] Add post to internal link building queue (link from older posts)
